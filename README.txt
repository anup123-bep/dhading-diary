DHADING DIARY — FREE WEBSITE

This is a static website and requires no paid theme, plugin, database, or server.

FILES
- index.html        Homepage
- category.html     Category pages
- contact.html      Contact page
- style.css         Blue media design
- script.js         Mobile menu, Facebook sharing, category rendering

HOW TO USE
1. Upload all files to a static hosting service such as GitHub Pages or Cloudflare Pages.
2. Open index.html.
3. Replace the demo headlines, images and contact details with your own.
4. The category tabs use category.html?cat=... and work without a database.

IMPORTANT
- Demo images currently load from Unsplash over the internet. For a fully self-contained site, download your own images and replace the image URLs.
- The contact details are placeholders and should be changed.
- This version is designed as a free static news portal. It does not include a login/admin panel or database.
